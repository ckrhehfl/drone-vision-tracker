# 시험 보고서

## 재현 정보
날짜 / 수행자 / commit / 설정 파일 해시 / 모델 해시 / 데이터 버전 / split·세션 / OS·GPU / 카메라 해상도·FPS·노출 / 장소·거리·속도·조명 / 보정 버전.

시험 전 확정한 영역 버전·확정 시각 / 카메라 배치 / 위치·높이·경로 / 사람이 잰 거리 /
축 보정과 별도 2축 허용 영역 / 케이블·간섭 조건 / 현재 시야를 각각 기록한다. 미측정은 미측정으로 둔다.

## 시험 종류
문서 검사 / 단위시험 / 모의 통신 / 녹화 영상 / 실물 한 축 / 두 축 / 통합 중 해당 항목을 표시.

## 결과
측정 방법 / 반복 수 / 분모·제외 조건 / 지표 / 목표 / 측정값 / 통과 여부 / 원본 로그 위치.

영역 내 추종 시험과 계획된 영역 밖 제한동작 시험을 분리한다. 영역 내 놓침·프레임 드롭·
추종 실패를 사후 제외하지 않는다. HOLD 성공은 추종 성공으로 세지 않는다. 포화·소실을
구분하며 명령값/ACK/포화 신호를 실제 축 위치·모터 스톨 측정으로 표현하지 않는다.

## 예외와 한계
실패 장면, 재현 방법, 미실행 시험, 측정 불가 항목, 안전 점검, 후속 조치. ACK를 실제 각도로 보고하지 않음.

실물 시험이 필요하면 승인/감독하에 축 방향·조합 간섭·케이블 여유·전압 강하·리셋·발열을
관찰하고, 정의한 영역에서 실제 입력 FPS·처리 FPS·호스트 지연·지정 드론 검출/추종 결과를
분리 기록한다. 기대 결과는 사전에 동결한 범위/목표와 대조한다. 승인 전 구동·강제 끝단 시험은 하지 않는다.
