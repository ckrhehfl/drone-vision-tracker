# 모델 — 가중치는 로컬 보관

공개 Seraphim 일부 데이터로 학습된 [쿼드콥터 YOLOv8n 모델](seraphim-yolov8n.md)을
로컬 GUI 기본 모델로 사용할 수 있다. 출처·고정 revision·해시·변환 내용과 추가 학습 방법을 기록했다.
프로젝트의 지정 드론으로 직접 학습·검증한 모델은 아직 없다. 큰 바이너리는 Git 추적에서 제외한다.

임시 수동 GUI에는 로컬에 준비된 [범용 ViT 추적 모델](vittrack.md)을 사용할 수 있다.
이 모델은 지정 영역 추적용이며 드론 검출 학습 모델과 구분한다.
