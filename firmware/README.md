# Arduino Uno 0번 모터 수동 시험

## 0·1번 모터 키보드 시험

`servo01_manual_safe/servo01_manual_safe.ino`와 카메라 GUI의 **0·1번 모터 수동 조작** 패널
(또는 **0·1번 모터 실행.command**)을 함께 사용한다. 기존 0번 전용 스케치와 프로그램은
별도로 보존한다. Arduino IDE 시리얼 모니터와 다른 모터 조작 창은 닫는다.

서보 외부 전원을 분리한 상태에서 새 스케치를 Uno에 업로드하고 Uno USB와 PCA9685 로직
전원을 껐다가 다시 켠다. 두 출력에 이미 PWM이 남아 있으면 연결이 잠긴다. GUI에서 업로드와
전원 재시작을 확인한 뒤 연결한다. 영점 자동 복귀가 켜져 있다면 연결 직후 초기 출력이
자동으로 전송된다. 서보 외부 전원을 다시 연결하는 순간에도 모터가 움직일 수 있으므로
기구를 지지한다. 자동 복귀가 꺼져 있다면 외부 전원 연결 후 각 축의 **초기 출력**을 직접
선택한다. 첫 출력은 현재 축 위치와 다르면 즉시 움직일 수 있다.

1번은 사용자가 시험을 요청한 80~330틱에서 동작한다. 이는 0번과 같은 명령 범위일 뿐
1번에 장착된 기구의 안전 끝점은 아직 확인되지 않았다. 205~216틱 시험과 80틱 초기 출력 후
양방향 움직임은 사용자가 확인했지만, 전체 구간의 안전 여부는 확인되지 않았다.
자동 복귀가 꺼진 수동 모드에서는 구동을 잠근 상태에서 **1번 초기 출력**을 눌러 값을 직접
선택하고 **구동 허가**를 누른다. 첫 출력은 즉시 움직일 수 있으므로 마지막 명령과 실제 기구
위치를 고려한다. 자동 복귀가 완료된 경우에는 이미 초기 출력과 구동 허가가 설정되어 있다.
파란 영역에 초점을 맞춘 뒤 W/↑ 또는 S/↓를 누른다. 방향은 아직 실측되지 않았으며 반대라면 잠근 후
**1번 W/S 방향 반전**을 선택한다. 0번은 A/D 또는 ←/→이며 숫자 입력도 0번에 적용된다.
범위를 조금씩 넓히며 상태에 표시되는 마지막 PWM 명령을 확인한다. W/S는 영문 입력에서 사용한다.
A/D 또는 ←/→와 W/S 또는 ↑/↓를 함께 누르면 두 축이 동시에 움직인다. 한 축의 키를 놓으면
그 축만 목표 진행을 중단한다. 같은 축의 반대 키를 함께 누르면 해당 축은 움직이지 않는다.
창 초점 이탈이나 잠금은 두 축의 목표 진행을 중단한다. 키를 놓아도 모터는 마지막 PWM 목표까지
움직일 수 있다. 표시되는 틱은 명령값이며 실제 기계적 각도와 전체 범위는 미확인이다.

**영점 자동 복귀 (각 205틱)**를 체크하면 연결된 상태에서 미설정 축을 205틱으로 초기화하고,
구동 허가 후 두 축의 목표를 205틱으로 설정한다. 선택은 `config/local/servo01-auto-home.json`에
저장되며, 다음 실행에서도 사용자가 연결을 누르면 같은 동작을 한다. 처음에는 체크되지 않는다.
기존 스케치는 계속 수동 조작할 수 있으나 자동 영점은 최신 `servo01_manual_safe.ino`를
업로드해야 한다. 체크를 해제하거나 잠그면 진행 중인 복귀를 중단한다. 이동 중 방향키를 누르거나
숫자 목표를 입력하고 Enter 또는 **이동**을 누르면 복귀가 중단된다. 프로그램은 서보의 실제
위치를 읽지 못하므로 첫 출력이나 서보 외부 전원을 다시 연결하는 순간 축이 움직일 수 있다.

## `servo0_manual_safe.ino`를 이용한 조작

`servo0_manual_safe/servo0_manual_safe.ino`는 사용자가 제공한
`servo0_manual.ino` 예제의 0번 채널 범위와
방향을 사용한다. 기존 스케치는 Uno가 리셋될 때 205틱을 출력할 수 있다. 서보 외부 전원을 끈
상태에서 안전 스케치를 Uno에 업로드하고, Arduino IDE 시리얼 모니터를 닫는다.
Arduino Library Manager에서 `PCA9685_RT` 0.7.4가 필요하다.

서보 외부 전원을 끈 상태에서 Uno USB와 PCA9685의 로직 전원도 모두 껐다가 다시 켠다.
**0번 모터 실행.command**를 열고, 안전 스케치
업로드와 로직 전원 재시작을 확인한 다음 **연결**을 누른다. 상태가 정상인지 확인한 뒤
서보 외부 전원을 연결한다. 기구를 지지하고 **초기 출력**에서 명령값 0~180을 직접 선택한다.
첫 출력은 현재 축 위치와 다르면 움직일 수 있다. 이전 PWM이 활성 상태인 채 Uno가 시작되면 잠긴다.
연결 오류나 Uno 재시작 뒤에도 서보 전원을 끈 상태에서 로직 전원을 다시 시작해야 한다.

**구동 허가** 후 파란 영역을 선택하고 A/← 또는 D/→를 누르면 0번 채널을 단계적으로 움직인다.
키를 놓거나 초점을 잃으면 진행 목표의 중단을 요청한다. 통신이 지연되면 PWM 갱신이 잠시 더
이어질 수 있다. **추가 명령 잠금**, Esc, 창 닫기는 전원 차단이 아니며 모터가 마지막 PWM
목표까지 움직일 수 있다.
숫자 0~180을 입력하면 해당 목표로 단계적으로 이동한다. 임시 범위는 80~330틱이며 숫자는 실제 회전각이 아니다.

로컬/CI에서는 Arduino CLI 1.5.1과 `arduino:avr@1.8.8`로 컴파일만 한다. `.venv/bin/python -m tools.ci`는 장치를 열거나 업로드하지 않는다.
