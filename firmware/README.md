# Arduino Uno 0번 모터 수동 시험

PCA9685 0번 채널(아래쪽 축)을 A/D 또는 ←/→로 시험한다. 카메라의 자동 추적이나 1번 채널과 연동되지 않는다. 추적용 [Serial v1 설계](../docs/02_serial_protocol.md)와 별개의 수동 시운전용 스케치다.

1. `pan_keyboard/pan_keyboard.ino`를 Arduino Uno에 업로드한다. Arduino IDE 시리얼 모니터는 닫는다.
2. 카메라 GUI의 **0번 모터 수동 조작**을 열거나 Finder에서 **0번 모터 실행.command**를 실행한다. 포트(`/dev/cu.usbmodem11301` 또는 현재 보드 포트)를 선택하고 **연결**을 누른다.
3. 출력 명령이 `미설정`이면 기구를 지지한 뒤 **초기 출력 설정**을 사용한다. 확인한 시작 PWM을 직접 입력한다. 현재 위치와 다르면 첫 명령에서 움직일 수 있다. 이미 205~410틱의 이전 출력이 있는 경우 그 명령값을 그대로 이어받는다.
4. 현재 출력 주변에 표시된 작은 시험 범위부터 시작한다. 움직일 공간과 케이블 여유를 확인하고, 실제 확인한 최소·최대 PWM을 넣은 뒤 **구동 허가**를 누른다. 파란 영역에 초점이 있을 때 A/← 또는 D/→를 누르고 있으면 이동한다. 실제 좌우가 반대라면 **좌우 방향 반전**을 선택한 뒤 다시 허가한다.
5. **목표 숫자(0~360)**에 정수를 넣고 Enter나 **이동**을 누르면 허가 범위 안에서 해당 PWM까지 단계적으로 이동한다. 이전 눈금과 같이 0=205틱, 180=307틱, 360=410틱이다. 예를 들어 205~210틱만 허가했다면 5나 8을 먼저 시험할 수 있다. 숫자는 실제 각도가 아니다.
6. 키를 놓으면 마지막 PWM을 유지한다. 양쪽 동시 입력은 이동하지 않는다. 숫자 이동 중 키를 누르면 키 조작으로 전환된다. 조작 창 밖으로 초점이 옮겨지거나 Esc, **정지·잠금**, 창 닫기를 사용하면 다시 허가해야 한다. USB 단절 시에는 Arduino에서 300ms 동안 유효한 갱신이 없으면 이동 명령을 잠근다.

범위는 이전 시험의 205~410틱(약 1~2ms)이며 실제 각도 또는 장착 상태의 안전 범위를 뜻하지 않는다. PWM은 50ms에 최대 1틱 바뀐다. `HOLD`와 잠금은 전원 차단이 아니다. 연속 회전형 서보에는 사용하지 않는다.

로컬/CI에서는 Arduino CLI 1.5.1과 `arduino:avr@1.8.8`로 컴파일만 한다. `.venv/bin/python -m tools.ci`는 장치를 열거나 업로드하지 않는다.
