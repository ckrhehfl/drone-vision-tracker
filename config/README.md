# 설계용 설정 예제

JSON 파일은 앞으로 구현할 설정 로더의 출발점이다. 현재 이를 읽어 실행하는 추적 프로그램은 없다. 설치 버전·실제 포트·모델 경로·제어 계수·보정값을 가짜 숫자로 채우지 않았다.

복사 후 `config/local/`에 실제 값을 기록하고 검증한다. null은 미정이며 0으로 자동 변환해서 구동하면 안 된다. 보정 completed 플래그만 확인하지 말고 축 범위 순서, pulse 범위, 방향 ±1, 속도 양수, 실물 점검과 운영자 ARM을 모두 확인한다.

project.example.json의 max_frame_age_ms=100은 새 관측 사용 여부를 위한 초기 호스트 기준이고 카메라 센서 노출 시각을 뜻하지 않는다. 정량 목표와 측정값은 구분한다. 실물 구동은 기본 false다.
