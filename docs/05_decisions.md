## 주요 위험
- 5V6A 수치만으로 전원 여유를 보장할 수 없음: 동시 기동·전압 강하·접점 확인.
- 브라켓·점퍼·압착 단자 결합이 미검증: 억지 체결 금지, 필수 부자재는 승인 후 변경.
- 소형 드론·어두운 실내·블러: 실제 배포 조건 데이터와 노출·해상도 비교.
- 지연·유격·케이블 저항: 최신 프레임 처리와 저속 단계별 시험.
- 검출 예측을 실제 관측처럼 사용: observation_valid로 구분, stale 관측 구동 금지.
- 같은 모델의 자체 리뷰 한계: 별도 리뷰 + 결정적 테스트 + 사람의 실물 확인.
