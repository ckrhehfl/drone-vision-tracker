## PR 통과 기준
작업의 요구사항과 실제 변경을 연결하고 테스트 명령·결과·미실행 사유를 기록한다. 리뷰는 별도 Codex 작업에서 수행한다. 하드웨어 시험이 필요하지만 아직 못 한 PR은 ‘하드웨어 검증 대기’로 표시한다. 테스트가 없는데 CI 초록 표시만으로 완료 처리하지 않는다.

수정 재시도는 한 검토 주기 최대 2회로 시작한다. 같은 문제가 반복되거나 범위·비용·구조 변경이 필요하면 정리해서 사용자 판단을 받는다. 자동 병합 규칙이나 실행 중인 자동화는 이 패키지에 없다.
