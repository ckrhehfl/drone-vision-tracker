# 구독 리뷰 전달 검증

이 문서는 Phase 6의 작은 PR 검증 대상이다. 제품 코드·설정·하드웨어는 변경하지 않는다.
결과 게시 기반은 PR #2에서 통합했으며 Auto Fix와 Auto Merge는 아직 비활성이다.

검증 순서:

1. 현재 커밋 CI 성공 후 새 독립 ChatGPT 구독 reviewer가 전체 diff를 검토한다.
2. 전체 JSON을 Actions에서 검증하고 해당 커밋에 `codex-review` 상태를 게시한다.
3. 명시적으로 표시한 합성 실패 fixture로 finding 표시와 실패 상태 게시를 확인한다.
   이 fixture는 실제 AI finding이나 제품 결함이라고 보고하지 않는다.
4. 문서 커밋을 추가해 이전 SHA의 결과를 거부하는지 확인한다.
5. 새 SHA에서 CI와 독립 리뷰를 다시 실행하고 PASS 게시까지 확인한다.

같은 PR에 커밋이 추가되면 기존 PASS도 새 커밋의 승인으로 사용하지 않는다.

실행 증거는 검증 완료 후 구축 상태 문서에 run ID와 SHA를 기록한다.
실제 카메라·검출 품질·Serial·서보·펌웨어·레이저는 이 검증으로 확인하지 않는다.
