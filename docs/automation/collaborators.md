# 팀원용 공유 스킬

저장소 접근 권한이 있는 팀원은 자신의 Codex에서 이 저장소를 열어 공통 스킬을 사용할 수 있다.
작성·push·병합에는 각자 GitHub 계정의 기존 저장소 권한이 적용된다.
특정 소유자 계정이나 허용 이름 목록에 종속되지 않으며, 다른 사람의 로그인 정보를 공유하지 않는다.

1. 저장소의 최신 main을 가져오고 본인 계정으로 Codex와 GitHub에 로그인한다.
2. README의 Python 개발 환경을 준비한다.
3. Codex에서 `$dev-orchestrator <기능 요청>`으로 시작한다.
4. 별도 세션의 `$review-orchestrator`로 리뷰하고, 필요하면 `$fix-findings`를 사용한다.
5. `$decision-gate`가 현재 증거를 판단한다. 요청에 병합이 포함되어 있으면 담당 Codex가
   보호된 PR을 병합한다.

자세한 명령과 PR 인계 기록은 [실행 안내](development.md)를 따른다.
PR당 최대 수정 2회는 팀원·PC가 바뀌어도 합산한다.
일반 코드 판단을 사용자에게 넘기지 않으며, 사람/실물/권한이 꼭 필요한 경우에만
[운영 규칙](operating-policy.md)의 형식으로 요청한다.

GitHub Actions는 CI를 실행한다. 별도의 AI API Key, 소유자 PC 접수, 시간별 감시,
공용 봇 계정은 필요 없다. 스킬은 요청한 Codex 세션에서 실행하는 작업 지침이다.
새 팀원의 실제 환경 실행은 각자의 인증과 설치 후 확인해야 한다.
